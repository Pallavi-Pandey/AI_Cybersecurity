# 6. Career Roadmap

## Roles to aim for
- SOC analyst, detection engineer, incident responder, threat hunter
- Cloud security engineer, application security engineer
- AI security / ML security engineer, GRC and risk analyst

## Skills to build
- Foundations: networking, operating systems (Linux/Windows), scripting (Python, Bash), SQL.
- Security core: web vulnerabilities (OWASP Top 10), logging and SIEM queries, MITRE ATT&CK, cloud basics.
- AI/data: Python data stack, basics of ML evaluation (precision/recall), LLM application risks.

## Practice and proof of work
- Home lab, CTFs (TryHackMe, Hack The Box, picoCTF), Blue Team Labs.
- Write-ups, GitHub projects, small detection or log-analysis tools.
- Certifications to consider: CompTIA Security+, Google Cybersecurity Certificate, then role-specific (BTL1, AZ-500, CEH, OSCP).

## 90-day starter plan
- Days 1–30: networking, Linux, Python, security basics.
- Days 31–60: SIEM/log analysis, MITRE ATT&CK, two CTF-style labs.
- Days 61–90: one portfolio project (e.g., log anomaly detector), publish write-ups, apply for internships.
