# Lab 06: Build Your Career Roadmap and Portfolio (20 min)

**Goal:** leave with a personal plan and a first portfolio repo.

| Step | Time | What |
|---|---|---|
| Self-assessment | 5 min | fill in `my-roadmap.md` |
| Portfolio repo | 10 min | turn one lab from today into a GitHub project |
| Share | 5 min | pair up, explain your 90-day plan in 1 minute |

## Steps
1. Copy `my-roadmap.md` and fill in: target role, current skills (rate 1-5), gaps, next three actions.
2. Create a GitHub repo for today's lab you enjoyed most (phishing classifier, login anomaly detector or alert triage). Add a README with: problem, approach, result, what you would improve.
3. Pick a CTF/lab platform (TryHackMe, picoCTF, Blue Team Labs) and book 3 sessions in your calendar this month.

## Portfolio checklist
- [ ] Clear README with a screenshot or sample output
- [ ] Runs from `requirements.txt` in one command
- [ ] No secrets or real personal data committed
- [ ] One paragraph on limitations (false positives, synthetic data)
